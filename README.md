# Rei Veicular

CRIE UMA PLATAFORMA WEB COMPLETA, PROFISSIONAL E MODERNA DE CONSULTA VEICULAR CHAMADA:

PESQUISA DO REI 👑
Slogan: “A verdade sobre o veículo, antes de fechar negócio.”

O sistema deve ter como inspiração plataformas profissionais de consulta veicular, como serviços de consulta pela placa, porém com identidade própria, visual premium, moderno e confiável.

OBJETIVO DO SITE:

Criar uma plataforma onde o cliente digita a PLACA do veículo e recebe uma consulta completa e organizada com todas as informações disponíveis através de APIs e bases de dados legalmente integradas.

O sistema deve funcionar como uma central de inteligência veicular.
